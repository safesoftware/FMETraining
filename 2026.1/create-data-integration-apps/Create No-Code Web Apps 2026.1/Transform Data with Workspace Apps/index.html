FME Flow Services

When you publish a workspace to FME Flow, the publishing wizard prompts you to register your workspace with a service. Then you must select a service to use when your workspace runs on FME Flow. For a workspace to run on FME Flow, you must register it with one of the FME Flow services; otherwise, the FME Engine will not know how to carry out your translation. 

 

The most common services are Job Submitter, Data Download, and Data Streaming, all of which are transformation services. Transformation services control how FME transforms and presents your output data when you run your workspace on FME Flow. 

To change the services a workspace is registered with, you may publish the workspace from FME Form to FME Flow again or edit the services from the repository in Workspaces. For training on editing a workspace's registered services, see Deploy Workspaces on FME Flow or our documentation on Transformation Services. 

Job Submitter 

The Job Submitter transformation service is most similar to running your workspaces on FME Workbench. The FME Engines execute the translation and write the data to the locations specified in the workspace's writers. When the translation is complete, FME Flow displays a status and the number of features written. 

Data Download

FME Flow's Data Download service packages the output data into a zipped folder and presents it to the user running the workspace as a downloadable URL. You click the URL link, and the zipped file downloads. From there, you extract the folder and access the data. If you register a writer with the Data Download service, it will not write the data to the location specified in the writer; instead, it will package the data into a zipped file by default. It is possible to configure your workspace writers to write the data and also package it into a zip folder, with duplicate writers and only one included in the Data Download service. 

Data Streaming

The Data Streaming service is similar to the Data Download service in that FME Flow doesn't write the data to the locations specified in the writers by default. Instead, FME Flow immediately streams the data back to you in the browser. Only some formats are compatible with the Data Streaming service, including HTML, PNG, KML, GeoRSS, GeoJSON, PDF, and more. If your output format is not compatible or the workspace produces multiple outputs, FME Flow will package the data into a zipped file and immediately download it instead. 

   

The Data Download and Data Streaming services benefit FME Flow workspace apps by letting you access output data immediately without navigating to the destination data storage location. With workspace apps, these services complete self-serve workflows by letting users access data by downloading it or streaming it in the browser. 

Workspace App Services

When you create a workspace app, you must select the service you would like to use to run your workspace. While you may register a workspace with multiple services, a workspace can only run using one service at a time, and each app can only use one service at a time. For example, you may register your workspace with both the Job Submitter and Data Download services; however, when creating your app, you must select either the Job Submitter or Data Download service to run the workspace. Each time the app runs the workspace, it uses that transformation service. You can edit the app and change the service, but it can run with only one service at a time. 

When you run a workspace app, FME Flow presents the Data Download and Data Streaming outputs to you in the same way as running a workspace manually on FME Flow. There's no difference in output when using an app; it simply presents the output to you on the app browser page. 

Exercise

The content used in this lesson builds on the previous lesson. To do this exercise, please complete the exercise in Run Workspaces through Apps. 

Jennifer continues working with her CAD Data Validation app. In this workflow, it's slightly inconvenient for end users to find and open the HTML report to get the validation results. She wants the app to hand the results back directly, so she needs a different transformation service.

In this exercise, you will:

  • Change a workspace app from the Job Submitter service to Data Download.
  • Change the same app to Data Streaming and compare how each service returns the results.

1) Change the Service to Data Download

  • On FME Flow, open Flow Apps and select the Workspace Apps tab.
  • Click your CAD-Data-Validation app.
    • The editing page offers the same options as the page you used to create the app.

  • From the Service drop-down, select Data Download.

  • Expand Parameter Defaults and confirm the only parameter left is Source AutoCAD DWG/DXF File(s).
    • The Destination HTML File parameter is gone. Data Download packages the report into a zip file and returns a URL, so the app user can't set a destination.

  • Click Save at the bottom of the form.

2) Run the App with the Data Download service

  • Click View App again to reopen the app.
    • If you still have the app open from the previous exercise, you can refresh the tab to update the app. 
  • Click the X to remove the default bad_data.dwg dataset as the source file.
    • Because the app uses the Data Download service, FME Flow no longer shows the Output Report File parameter. 

  • Drag good_data.dwg from C:\FMEData\Resources\DigitalPlanSubmission\ into the Upload Files area.

  • Click Run.
    • FME Flow runs the workspace with the Data Download service, zipping the output into a downloadable zip file, and presents the URL once the translation is complete. 

  • Click the Data Download URL to download the zip file.

  • Extract the zip file, open the HTML_1 folder, and open validation.html.
  • Confirm the report shows validation succeeded.
    • No features failed this time, so the report lists no failures.

3) Change the Service to Data Streaming

Data Download is convenient, but it still asks the app user to download and extract a file. Data Streaming removes those steps by returning the report straight to the browser.

  • Return to FME Flow and open your CAD-Data-Validation app for editing.
  • From the Service drop-down, select Data Streaming.

  • Scroll to the bottom and Save the app. 

4) Run the App with the Data Streaming service

  • Open the app again.
  • Run the app again, leaving the default bad_data.dwg source file as the input.
    • The app shows a message while an FME Engine processes the workspace.

  • FME Flow displays the HTML validation report directly in the browser.

The Data Streaming service best suits Jennifer's workflow, as it eliminates the need for users to navigate to and open the HTML report, returning validation results directly to the app.
