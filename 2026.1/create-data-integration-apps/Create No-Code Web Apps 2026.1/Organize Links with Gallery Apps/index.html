Gallery Apps

Gallery apps act as landing pages to link to other apps and websites. You add links to workspace apps, automation apps, and external URLs that display with customizable text and icons on the Gallery App page. Like all other Flow apps, you access gallery apps from a single URL. By linking to other apps and websites from the gallery app, you can group and share content by sharing a single URL: the gallery app itself. 

Like other Flow apps, the Create gallery app opens a form you fill out to create your gallery app. The customization options are the same as in other Flow apps, allowing you to tailor the app to your organization's branding by adding color, icons, and images. 

  

Links are unique to gallery apps and reference the individual links in your gallery app displays. For each link, select "Add" and then choose your link type.

The window will automatically populate parameters for you to fill out. Select your app or paste your URL, then customize how the link appears in the gallery app. 

The Label appears beneath the image in the gallery app, while the Tooltip text appears when you hover over the image. The image appears as an icon that you may select to open the link. If you do not add an image, FME Flow will display default images that reflect the link type.

Although there isn't a link type for it, it's actually possible to link to another gallery app from a gallery app. To do this, you just select the URL link type and set it to the gallery app's custom URL.

App Permissions

Gallery apps may be publicly accessible, provided that your FME Flow is publicly accessible. Alternatively, you can set App Security to Private to restrict access to specific FME Flow roles and users. 

Gallery app security settings only apply to the gallery app page itself. You control permission to access the linked workspace and automation apps separately and individually from those app creation and editing pages. If you don't have permission to a workspace or automation app, you will still see the link on the gallery app page, but you will get an error when you open it and try to log in to access the app. 

Exercise

Frank, an FME Flow administrator, wants to stop sending his colleagues a different link for every Flow app the team builds. He needs one page that gathers the apps together, alongside a link to background reading for people who have never used a Flow app. A gallery app gives him a single URL to share.

In this exercise, you will:

  • Create a gallery app and add links to a workspace app, an automation app, and an external site.
  • Reorder the links and open the finished gallery app.

1) Create the Gallery App

  • On FME Flow, open Flow Apps, select the Gallery Apps tab, and click Create.

  • Enter a Name, a Title, and a Description for the app.

2) Add a Link to a Workspace App

  • In the Links section, click Add.

  • For the link type, select Workspace App.

  • Select the CAD-Data-Validation app.
  • Enter Data Validation as the Label, and CAD Data Validation workspace app for the Tooltip. 
  • Upload create-a-gallery-app_icon.png (C:\FMEData\Resources\FlowApps\create-a-gallery-app_icon.png) to replace the default image.

  • Click Add Link.

3) Add a Link to an Automation App

  • In the Links section, click Add again.

  • Select the CityProjNotifyList app and fill in the Label and Tooltip.
    • Add no image this time; the link will show the default icon for its type.

  • Click Add Link.

4) Add a Link to a Website

  • Add another link.
  • Set the Type to URL. 
  • In the URL field, enter https://support.safe.com/hc/en-us/articles/25407756069901-Getting-Started-with-FME-Flow-Apps
    • This is an introductory support article on FME Flow Apps. If someone is unfamiliar with how FME Flow Apps work, this is a useful resource. 
  • Fill in the Label and Tooltip, then click Add Link.

5) Reorder the Links

  • In the Reorder column, click Move Up twice for the URL link so it sits first.

6) Create and Open the Gallery App

  • Leave App Security set to Public and click Create at the bottom of the page.

  • Click View App, then test each link.

You have built a gallery app that gathers two Flow apps and a reference article behind a single URL, allowing you to share all three links from the single gallery app URL.
